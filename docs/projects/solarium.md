# Solarium

Self-contained works across any medium — each built around a single premise, complete in itself.

::: info Status: Seeding ◔
Currently at [para-garden/solarium](https://github.com/para-garden/solarium).
:::

## Core Concept

Each piece is an island. No shared universe, no ongoing world, no accumulated narrative debt. The premise is the whole justification — make it, finish it, move on.

Medium varies per piece: text, interactive, visual, audio — whatever serves the idea.

Prior art: Heinlein's "All You Zombies" (complete in one sitting, every element load-bearing), Greg Egan's short fiction (premise-driven, medium varies, self-contained), Asimov's I, Robot (self-contained pieces that accumulate without connecting).
