# Existence

Text-based HTML5 game. Power anti-fantasy — constrained agency without judgment.

::: info Status: Growing ◔
Vanilla JS, no frameworks, no build step. Currently at [para-garden/existence](https://github.com/para-garden/existence).
:::

## Core Concept

A text-based game where you have constrained agency. Not a power fantasy — a power anti-fantasy. You make choices, but the choices are bounded. The game doesn't judge you for what you pick. It just shows you what happens.

## Tech

- Vanilla JavaScript — no frameworks, no build step
- HTML5 — runs in a browser
- Deliberately minimal tooling
